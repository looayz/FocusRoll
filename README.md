# FOCUSROLL — Productivity Randomizer

Application PWA minimale et ultra-concentrée :
> "You don't decide. You focus."

## Technologies
- React 19 + TypeScript + Vite
- Tailwind CSS v4 + Framer Motion
- Dexie (IndexedDB) pour persistance locale sans compte
- Audio synthétisé Web Audio API (haptic/clicks/bell zens)
- PWA installable (manifest, service worker, offline-ready, mode standalone desktop/mobile)

## Lancement
```bash
npm run dev
```
Accessible sur PC et mobile en mode PWA.
